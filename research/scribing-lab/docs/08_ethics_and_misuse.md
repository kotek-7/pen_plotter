# 08 Ethics And Misuse

## 基本認識

この研究は、本人の手書きと区別されにくい文字生成を目指すため、濫用リスクが高い。特に署名、契約書、申請書、学校課題、本人確認文書への悪用が想定される。

## 研究対象外

- 署名生成。
- 本人同意のない筆跡模倣。
- 公的文書や契約文書への利用。
- 判別回避や偽装を目的とした評価最適化。

## 必須制約

- writer profile は本人同意のあるデータだけから作る。
- 収集データには同意範囲を明記する。
- profile と元データを第三者へ再配布しない。
- 生成物には可能な限り metadata を付与する。
- 実験参加者には生成物の用途を説明する。

## 技術的対策

- 署名に類する短い固有筆跡サンプルを profile 学習から除外する。
- profile export に利用条件 metadata を含める。
- 研究出力には invisible ではなく検査可能な provenance を残す。
- evaluation harness は「判別器回避」ではなく「自然さ評価」として設計する。

## 公開時の注意

- 学習済み writer profile を公開しない。
- 個人の筆跡サンプルを公開しない。
- データ取得スクリプトには同意管理を含める。
- README に禁止用途を明記する。

## 判断基準

研究上の改善が、本人性の偽装や署名模倣へ直接つながる場合、その機能は公開対象から外す。
