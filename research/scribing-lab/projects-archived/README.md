# Archived Projects

旧 `projects/` 配下の研究コードを参照用に残す。

このディレクトリは現行の新規実装基盤ではない。中の README、research plan、CLI、
schema、テストは、旧方針である `projects/` 分割と evaluation-harness 中心の研究運用を
前提にしている。そのため、現行方針とは意図的にズレている。

現在の研究作業は、原則として `../engines/`、`../runner/`、`../runs/`、`../evaluation/`
を中心に進める。

旧コードを読む場合は、必要な設計判断やデータ構造だけを参照し、直接依存を増やさない。
